# Bug Fix

再現から検証済みの結果まで、修正を最後まで担当する。

- まず再現する。エラーとそれが指すコードを自分で読み、報告文だけで診断しない。再現に必要な情報が足りなければ、何が不足しているかを明示してそこで止める。
- 根本原因を最小限の変更で直す。症状だけを覆い隠したり、変更を無関係なリファクタリングに広げたりしない。
- 触った範囲をプロジェクト自身の check で検証する。UI の変更は実ブラウザまたは Playwright でも確認し、UI テストが無い場合はその旨と手動確認の内容を記録する。
- 検証が通らなければ再現に戻る。テストや期待値を変えて green にしない。
- 実行したコマンドと、直ったと判断した根拠を報告し、PR の説明や報告にも同じ内容を書く。
